# ذاكرة عبود المحلية

في الإصدار الأول تحفظ الملاحظات التي يضيفها المستخدم داخل مساحة التطبيق الخاصة باستخدام Android SharedPreferences.

مثال للأمر:
- احفظ أن موعد صيانة السيارة يوم الخميس
- ماذا حفظت

هذه الذاكرة محلية على الجهاز ولا تتم مزامنتها مع أي خادم.

## ما لم يدمج بعد
- نموذج لغوي محلي بصيغة GGUF أو غيرها.
- فهرسة واسترجاع دلالي للمستندات.
- تشفير مستقل للذاكرة.
- مزامنة اختيارية مشفرة.

لن يتم تنزيل نموذج كبير تلقائياً. يجب اختيار النموذج ومراجعته قبل إضافته لتجنب استهلاك مساحة الهاتف وذاكرته.
