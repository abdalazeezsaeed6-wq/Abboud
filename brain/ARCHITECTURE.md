# عقل عبود الهجين

## طبقات العقل
1. **الأوامر المحلية:** تعمل دون إنترنت وتنفذ الوظائف المسموح بها على Android.
2. **الذاكرة المحلية:** ملاحظات محفوظة داخل مساحة التطبيق، ولا ترسل إلى السحابة تلقائياً.
3. **العقل السحابي الاختياري:** واجهة متوافقة مع خدمات Chat Completions التي تقبل Bearer API key. لا يعمل إلا بعد إدخال إعدادات المزود وتفعيل الخيار يدوياً.
4. **العقل المحلي اللغوي:** لم يدمج بعد. سيضاف بعد اختيار ملف نموذج صغير متوافق مع قدرات الهاتف واختبار استهلاك الذاكرة والحرارة والسرعة.

## الخصوصية
- لا يوجد مفتاح API افتراضي في المصدر.
- يحفظ مفتاح الخدمة باستخدام Android Keystore وتشفير AES-GCM.
- لا ترسل الملاحظات المحلية أو سجل المحادثات إلى المزود في النسخة الحالية؛ يرسل نص السؤال الحالي فقط عند تفعيل السحابة.
- استخدم مزوداً موثوقاً، وراجع سياسة الاحتفاظ بالبيانات لديه.
- لا تضع أي أسرار في GitHub أو في ملفات المشروع.

## قيود النموذج المحلي
هاتف Galaxy S9+ بذاكرة 6GB يحتاج نموذجاً كمياً صغيراً. النموذج الأكبر ليس بالضرورة أسرع، وقد يسبب بطئاً أو إغلاق التطبيق بسبب ضغط الذاكرة. يجب قياس الأداء على الهاتف قبل اعتماد حجم النموذج النهائي.
