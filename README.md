# عبود | Abboud

مساعد Android شخصي باللغة العربية. المشروع يعمل بنظام هجين: أوامر محلية وذاكرة خاصة، نموذج لغوي محلي اختياري، وعقل سحابي اختياري عند إعداد مزود خدمة ومفتاح API.

## ما يتضمنه الإصدار التطويري
- واجهة محادثة عربية RTL.
- إدخال صوتي عبر خدمة التعرف على الكلام في Android، بعد إذن الميكروفون.
- نطق عربي عبر محرك TTS المثبت في الجهاز.
- أوامر محلية أساسية لفتح بعض التطبيقات والإعدادات، ضبط صوت الوسائط، وإظهار لوحة الاتصال.
- ذاكرة ملاحظات خاصة داخل التطبيق.
- إعداد اختياري لعقل سحابي متوافق مع واجهة Chat Completions. يحفظ مفتاح API مشفراً باستخدام Android Keystore وAES-GCM.
- محرك LiteRT-LM لتشغيل نموذج Qwen محلياً بعد تنزيله اختيارياً من داخل التطبيق.

## نموذج العقل المحلي
النموذج المستهدف: `Qwen3-0.6B_dynamic_wi4b32_afp32.litertlm` من `litert-community/Qwen3-0.6B`، حجمه المنشور نحو 329 MB وترخيصه Apache-2.0. لا يوضع داخل APK أو المستودع. ينزله المستخدم من شاشة إعدادات عبود بعد الموافقة على المساحة والاتصال.
المحرك المستخدم: `com.google.ai.edge.litertlm:litertlm-android:0.19.1`.
يعمل المحرك حالياً عبر CPU backend كخيار متوافق. الأداء الفعلي على كل هاتف يحتاج قياساً عملياً؛ لا توجد نتائج اختبار على Galaxy S9+ حتى الآن.

## العقل السحابي
من الإعدادات اختر `إعداد العقل السحابي`، وأدخل:
- عنوان HTTPS لمزود يدعم Chat Completions.
- اسم النموذج لدى المزود.
- مفتاح API الخاص بالمزود.

لا يأتي التطبيق بمفتاح API مضمّن. مفتاح ChatGPT أو اشتراك ChatGPT لا يُعد تلقائياً مفتاح API. لا ترسل مفاتيحك إلى GitHub أو تشاركها مع أحد.
عند تفعيل السحابة يُرسل نص السؤال الحالي فقط، ولا ترسل الملاحظات المحلية أو سجل المحادثات تلقائياً.

## المتطلبات
- Android API 24 أو أحدث.
- JDK 17.
- Android SDK Platform 36.
- Android Gradle Plugin 9.5.0.
- Gradle 9.6.0.
- Kotlin 2.4.0.

## البناء
```bash
gradle --no-daemon clean assembleDebug
```
