# عبود | Abboud

مشروع مساعد شخصي Android باللغة العربية. هذه أول نسخة تأسيسية للمشروع، وليست بعد المساعد الذكي الكامل.

## الموجود في المرحلة الأولى
- مشروع Android بلغة Java.
- واجهة محادثة عربية باتجاه RTL.
- إدخال صوتي عبر خدمة التعرف على الكلام المتاحة في Android، بعد طلب إذن الميكروفون.
- نطق عربي عبر محرك تحويل النص إلى كلام المثبت على الهاتف.
- ذاكرة ملاحظات محلية داخل مساحة التطبيق الخاصة.
- أوامر أولية لفتح الإعدادات وبعض التطبيقات، وضبط صوت الوسائط، وفتح لوحة الاتصال.
- طلب تأكيد قبل حذف الملاحظات.

## أوامر الذاكرة
- `احفظ أن موعد صيانة السيارة يوم الخميس`
- `ماذا حفظت`
- `امسح ذاكرتك` ثم اختر تأكيد الحذف من النافذة.

## حدود هذه النسخة
- لا يوجد نموذج ذكاء اصطناعي محلي أو سحابي مدمج حتى الآن.
- التعرف على الكلام يعتمد على خدمة التعرف المثبتة في الجهاز وقد يحتاج إلى الإنترنت.
- جودة النطق واللهجة تتوقف على الأصوات المثبتة في Android. اللهجة الحضرمية ليست مضمونة بعد.
- لا يوجد استماع دائم أو كلمة تنبيه في هذه النسخة.
- لا يتم إجراء مكالمات أو إرسال رسائل تلقائياً. أوامر الاتصال والرسائل الآمنة تحتاج اختيار جهة اتصال ومراجعة وتأكيداً في مرحلة لاحقة.

## متطلبات البناء
- JDK 17
- Android SDK Platform 36
- Android Gradle Plugin 9.5.0
- Gradle 9.6.0

## البناء
من بيئة تحتوي Gradle 9.6.0 وAndroid SDK:

```bash
gradle --no-daemon assembleDebug
```

الناتج المتوقع عند نجاح البناء:

`app/build/outputs/apk/debug/app-debug.apk`

## GitHub Actions
بعد كل دفع إلى الفرع `main)، ينفذ GitHub Actions عملية البناء ويرفع ملف APK كـ Artifact عند النجاح. لا يعتبر التطبيق جاهزاً للتثبيت قبل نجاح هذه العملية.

## الخصوصية
الملاحظات تحفظ داخل بيانات التطبيق على الهاتف ولا تتم مزامنتها إلى خادم في هذا الإصدار. لا تضع مفاتيح API أو كلمات مرور داخل المستودع.
