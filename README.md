# عبود | Abboud

مساعد شخصي عربي لنظام Android، يبدأ بمرحلة تأسيسية قابلة للتوسعة.

## المرحلة الأولى
- واجهة عربية من اليمين إلى اليسار.
- إدخال نصي ومحادثة أولية.
- التعرف على الكلام عبر خدمات Android المتاحة على الجهاز.
- نطق الردود عبر Android TextToSpeech مع اختيار صوت النظام العربي إن توفر.
- بنية أولية تسمح بإضافة محرك محلي وموصل سحابي وذاكرة محلية لاحقاً.

## متطلبات البناء
- Android SDK 35
- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- الحد الأدنى Android 7.0 (API 24)

## البناء
من مجلد المشروع:
```bash
gradle assembleDebug
```
ملف APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات مهمة
هذه نسخة تأسيسية وليست مساعداً ذكياً مكتملاً بعد. لا يوجد حالياً نموذج لغوي محلي مضمّن أو اتصال سحابي مهيأ أو استماع دائم لكلمة النداء. التعرف الصوتي يعتمد على مزود التعرف المثبت في Android وقد يحتاج إنترنت أو تنزيل حزمة لغة. لن ينفذ التطبيق اتصالات أو رسائل أو إجراءات حساسة دون إضافة صلاحيات وتأكيدات صريحة.

## الخصوصية
لا تضع مفاتيح API أو كلمات مرور داخل المستودع. ستضاف إعدادات الاتصال السحابي لاحقاً بطريقة آمنة.
